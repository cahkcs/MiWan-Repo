# MiWan-Repo

`pkg/<资源id>/<版本>/<文件名>` 这个约定路径直接读文件，
所以**维护者不需要在后台逐条填 git 地址**。

由 `tools/sync-repo.js` 自动生成，请勿手工改动目录结构。

> 130 字节的文本，安装必然失败且看不出原因。
